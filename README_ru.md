## 1. Новое определение проекта

EIDOLON — это не просто инструмент для «превращения логов чата в системный промпт».

**Официальное определение версии 1.2:**
> **«Дистиллировать вычислимые лингвистические, поведенческие, ритмические и контекстуальные паттерны из подлинных диалогов, управляемые L4-движком динамических отношений и эмоций, со строгой валидацией на независимых слепых тестовых выборках для обеспечения стилистической и фактологической точности живого человеческого присутствия.»**

## 2. Архитектура и 7 уровней дистилляции

| Уровень | Модуль | Математические и эмпирические характеристики | Артефакт |
| :--- | :--- | :--- | :--- |
| **Layer 1** | Лингвистический отпечаток | Частотность лексики, пропуск пунктуации, тире/волны/многоточия, распределение длины фраз | `language_model.json` |
| **Layer 2** | Модель условного стиля | Байесовская условная вероятность $P(\text{стиль} \mid \text{контекст})$, пороги эмоций | `style.json` |
| **Layer 3** | Дерево поведенческих решений | Ситуативные стратегии (юмор, эмпатия, анализ, встречные вопросы), переключение тем | `behavior.json` |
| **Layer 4** | Динамический диалоговый ритм | Задержка ответа по категориям длины сообщения, вероятность мульти-сообщений | `rhythm.json` |
| **Layer 5** | Моделирование ассетов и эмодзи | Стикеры, эмодзи и матрицы их смысловой привязки к контексту | `assets.json` |
| **Layer 6** | Модель мира и предыстория | Граф отношений, временная шкала, строгое разделение фактов из чата и введенных данных | `world.json` |
| **Layer 7** | Семя многоуровневой памяти | L0 буфер, L1 эпизодическая память (кривая забывания), L2 семантика, L3 картина мира | `memory_seed.json` |

## 5. Быстрый старт и мастер развертывания

```bash
git clone https://github.com/ysnsk111/eidolon.git
cd eidolon
npm install
npm run build:server
npm start
```

Шаги мастера онбординга:
1. **Шаг 0**: Выбор языка интерфейса (английский по умолчанию, русский, китайский, японский, корейский, французский, испанский).
2. **Шаг 1**: Подключение к API языковой модели и проверка simple-test.
3. **Шаг 2**: Указание пути к файлу истории сообщений и ввод дополнительной предыстории мира.
4. **Шаг 3**: Ввод токена Telegram-бота и User ID.
5. **Шаг 4**: Запуск службы и сопряжение по команде `/start`.
6. **Шаг 5**: Подтверждение запуска дистилляции (с отчетами в Telegram в реальном времени и очисткой служебных сообщений по завершении).

## 6. Справочник команд CLI

| Команда | Описание |
| :--- | :--- |
| `eidolon init` | Запуск интерактивного мастера и инициализация базы SQLite |
| `eidolon config [show\|set\|test]` | Просмотр, изменение настроек или проверка связи с LLM |
| `eidolon distill <file> [options]` | Запуск 7-уровневой дистилляции, телеметрии в Telegram и оценки |
| `eidolon evaluate <persona>` | Офлайн-оценка персоны и расчет метрики DSI |
| `eidolon validate <path>` | Проверка архива `.eidolon` на соответствие JSON-схемам |
| `eidolon persona [list\|activate\|install\|verify]` | Управление персонами: список, активация, установка, проверка |
| `eidolon memory [status\|compact\|export]` | Статистика памяти, сжатие устаревших фактов, экспорт |
| `eidolon bot [token\|user\|status]` | Управление токеном Telegram-бота и списком разрешенных пользователей |
| `eidolon service [start\|stop\|restart\|status]` | Управление фоновой службой Go |
| `eidolon logs [-n lines]` | Просмотр журнала работы демона |
| `eidolon status` | Общий статус всех подсистем среды EIDOLON |
| `eidolon clear [--mode all\|chat-memory]` | Очистка в 3 шага: полное удаление (all-clear) или сброс чатов и памяти (персоны сохраняются) |
